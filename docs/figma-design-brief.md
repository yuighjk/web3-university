# Web3 大学 — Figma 设计稿描述

## 产品概述

Web3 教育平台，用户用代币购买课程、学完获得链上证书。左侧导航 + 顶栏 + 内容区的后台布局风格。

---

## 全局样式

- 配色：主色 #7355f5（紫色），背景 #f7f7fb，卡片白色，文字 #171b2e
- 字体：Inter / PingFang SC，正文 14px，标题 20-24px
- 圆角：卡片 14px，按钮 8-10px，输入框 8px
- 阴影：卡片 0 2px 8px rgba(0,0,0,0.04)

---

## 页面列表（共 6 页）

### 1. 课程市场（首页）

```
┌─────────────────────────────────────────────┐
│ 左侧导航(220px)  │  顶栏(56px高)            │
│                   │  [Sepolia标签] [登录按钮] │
│ Logo + 标题       ├─────────────────────────┤
│ ──────────        │                         │
│ 📚 课程市场       │  Hero Banner            │
│ 🔄 兑换 YD       │  紫色渐变背景 + 标题     │
│ 🏪 创作者中心     │  "把每一次学习写进Web3"   │
│ 👤 个人中心       │  [探索课程] [获取YD币]   │
│ 👑 Owner管理      │                         │
│                   │  统计卡片 x3（横排）     │
│ [收起按钮]        │  课程数 | 价格 | 证书名  │
│                   │                         │
│                   │  课程卡片网格（2-3列）   │
│                   │  封面图+标题+价格+购买   │
└───────────────────┴─────────────────────────┘
```

### 2. 课程详情

- 顶部：课程大图 + 标题 + 价格 + 购买按钮
- 购买流程弹窗：步骤条（检查余额 → 授权 → 购买 → 完成）
- 已购买状态：显示视频列表（带播放图标）
- 底部：评论区

### 3. 兑换 YD

- 卡片式布局，居中
- 输入：USDC 数量 → 预估 YD 产出
- 按钮：[兑换] + [领取测试 USDC]
- 底部显示当前余额（YD / USDC）

### 4. 个人中心

- 顶部：头像 + 用户名（可编辑）+ 钱包地址
- 资产卡片：YD 余额 / USDC 余额
- Tab 切换：已购课程 | 我的证书 | 学习进度
- 证书卡片：紫色渐变边框 + 课程名 + 颁发日期 + SBT 标记

### 5. 创作者中心

- 提交课程表单：标题 / 描述 / 封面上传 / 视频链接 / 定价
- 我的课程列表：状态标签（待审核 / 已上架 / 已下架）

### 6. Owner 管理台

- Tab 切换：Provider 管理 | 课程审批 | 证书发放
- Provider 管理：表格（地址 / 角色 / 操作）+ 添加表单
- 课程审批：待审核列表 + [通过] [驳回] 按钮
- 证书发放：已完成学生列表 + [发证] 按钮

## 组件规范

| 组件 | 规格 |
|------|------|
| 侧边栏 | 展开 220px / 收起 64px（只显示图标，正方形40x40背景） |
| 顶栏 | 高 56px，左侧状态标签，右侧登录/头像 |
| 按钮-主要 | 紫色渐变 #7650ff→#6740ec，高 34px，圆角 8px |
| 按钮-次要 | 白底紫边，高 34px |
| 卡片 | 白底，圆角 14px，padding 20px |
| 标签 | 小圆角 6px，12px 字号，浅色背景 |
| 输入框 | 高 40px，圆角 8px，1px 边框 #ececf4 |
| 表格 | Ant Design 风格，斑马纹，行高 48px |

---

## 交互状态

- 购买按钮：默认 → 加载中（spinner）→ 成功（绿色勾）
- 侧栏收起：点击底部按钮，动画 0.2s，收起后只显示图标
- 课程卡片 hover：轻微上浮 + 阴影加深
- 交易进行中：步骤条显示当前阶段（签名/确认/完成）
