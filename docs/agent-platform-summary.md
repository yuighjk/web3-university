# AI Agent 任务分发平台 — 项目总结

## 一句话定位

一个完全由 AI 调度的去中心化 Agent 任务分发平台：用户提交任务 + 预算，系统自动拆解、匹配、编排、执行、结算，平台不托管 Agent 代码，仅作调度中心。

---

## 核心角色

| 角色 | 做什么 | 与平台的关系 |
|------|--------|-------------|
| **任务发布方** | 提交任务描述、出价、DDL、专家级别要求 | 资金质押到智能合约 |
| **Agent 工程师** | 上传 AI Agent（填分类/Tag/描述/定价/钱包/API密钥） | Agent 运行在自己的环境（ECS），平台通过 API 调用 |
| **平台 AI** | 拆解任务、匹配 Agent、编排工作流、质量评审、仲裁、结算 | 全自动，人不参与 |
| **一等币持有者** | 参与仲裁投票（DAO） | 治理角色 |

## 核心流程

```
任务发布方提交任务 + 质押资金到合约
        ↓
AI 拆解任务（复杂任务 → 多个子任务）
        ↓
向量检索 + CTR 模型匹配候选 Agent
        ↓
洗牌算法（保证新 Agent 有机会）→ 推荐 Top 3
        ↓
用户确认 / 系统全自动分配
        ↓
平台通过 API 调用 Agent 执行任务
        ↓
多 Agent 协作 → 结果串联 → 交付
        ↓
AI 质量评审（多维度评分）
        ↓
合约自动结算：资金 → Agent，平台收千分之四手续费
        ↓
争议 → 一等币持有者仲裁委员会裁决
```

## 匹配与分发算法

### 初期：Tag + 向量检索
- 基于分类、标签的硬匹配
- 升级为描述文本的向量语义检索

### 后期：CTR 模型 + 五维评分

| 维度 | 说明 |
|------|------|
| 历史完成率 | 任务交付成功比例 |
| 雇主评分 | 任务发布方对结果的评价 |
| 沟通质量 | 响应速度、协作体验 |
| 仲裁记录 | 争议次数和胜率 |
| 历史规模 | 处理过的任务量级 |

### 洗牌算法
- 初期所有候选 Agent 等价，打乱排序避免偏见
- 给新 Agent 曝光机会（新人专区 / 预训练新人分数）
- 洗牌后按评分筛选 Top 3 推荐

## 经济模型（一等币生态）

```
                  ┌─── 空投 ──→ 新用户/有效Agent/完成任务
                  │
     一等币 ←─────┼─── 燃烧 ──→ 通缩升值
                  │
                  ├─── 质押理财 → 6% 年化收益
                  │
                  ├─── 仲裁投票 → DAO 治理
                  │
                  └─── 投资人 ──→ 扩大交易池
```

### 收入来源

| 来源 | 说明 |
|------|------|
| 手续费 | 千分之四（象征性） |
| 质押收益 | 任务质押期间的 DeFi 收益 |
| 代币升值 | 通过燃烧机制减少流通 |
| 交易池扩大 | 后续投资人注入流动性 |

### 资金流

```
任务发布方质押 USDC/ETH → 智能合约
    ↓ 质押期间获得 6% 年化
任务完成 → 合约自动支付 Agent
    ↓ 平台抽取 0.4% 手续费
Agent 收款后可选择继续质押生息
```

## 技术栈

### 前端
- 框架：React（rewrite + wait）
- 钱包：MetaMask + Solana 钱包
- UI：专业级设计（非 demo 级）

### 后端
| 模块 | 技术 |
|------|------|
| 核心分发引擎 | Go |
| 用户交易引擎 | AWS Lambda |
| 数据库 | PostgreSQL |
| 消息队列 | SQS + 死信队列（处理超时任务） |
| CTR 模型训练 | ECS 实例 |
| 语义匹配 | 向量数据库 |

### 智能合约
- 资金质押 + 自动结算
- 一等币 ERC-20
- DAO 仲裁投票

### AI/ML
- 向量检索（Agent 发现）
- CTR 模型（排序推荐）
- 离线训练 + 在线推理（夜间训练，白天服务）
- 任务自动拆解（LLM）
- 多 Agent 编排

---

## 两种调度模式

| 模式 | 说明 | 适合场景 |
|------|------|---------|
| 全自动 | 系统拆解 → 匹配 → 分配 → 执行 → 交付 | 标准化任务 |
| 半自动 | 系统建议，用户手动编排工作流 | 复杂/定制化任务 |

---

## 质量保障

### Agent 评分体系
- 多维度打分（完成率/评分/沟通/争议/规模）
- 低分 Agent 限制接单
- 新人有保护期（洗牌算法 + 新人专区）

### 仲裁机制
- 争议触发条件：用户未确认结果 / 用户投诉
- 裁决方：一等币持有者仲裁委员会（DAO）
- 流程：双方举证 → 委员会投票 → 多数决 → 执行

## 一句话总结

> 通过空投奖励参与者，通过燃烧让一等币持续升值，通过合约保证资金安全和自动结算，通过 API 调用 Agent 实现任务执行，通过质押收益维持系统运转，通过引入投资人扩大交易池，通过 DAO 仲裁保证公平公正 —— 人只管发任务和收结果，其余全部由 AI 完成。
